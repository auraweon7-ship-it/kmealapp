# 급식 어때? 🍱

> **제8회 교육 공공데이터 AI 활용대회 출품작**
> NEIS·학교알리미 공공데이터와 3대 LLM(Claude·ChatGPT·Gemini)을 융합한 전국 학교급식 인터랙티브 플랫폼

`v1.6 · SCHOOL MEAL COMPASS`

## 🎯 차별화 포인트

- **공공데이터 3종 통합** — NEIS · 학교알리미 · 식약처 영양 DB
- **3대 LLM 멀티 호스팅** — Claude · ChatGPT · Gemini 자유 전환
- **AI Vision 가정식 분석** — 학교 급식 + 가정식 합산 영양 균형
- **다문화 학생 지원** — 8개 언어 + 메뉴 자동 번역 + 다국어 음성
- **GIS 영양 격차 분석** — 자치구 단위 사각지대 자동 발견
- **알레르기 안전망** — 19종 표준 알레르기 + 5일 위험 자동 스캔
- **B2B 영양사 모드** — 학교 운영 KPI + AI 식단 자동 설계
- **음성 인터페이스** — Web Speech API 핸즈프리 질의

## 🌐 사용 API

| API | 용도 |
|---|---|
| **NEIS 학교기본정보** | 17개 시도 학교 좌표·주소 |
| **NEIS 급식식단정보** | 오늘 메뉴·칼로리·영양·원산지·알레르기 |
| **학교알리미 공시정보** | 학생 수·교원 수·급식 만족도 |
| **Anthropic Claude** | AI 분석·메뉴 생성·Vision |
| **OpenAI ChatGPT** | AI 분석·메뉴 생성·Vision |
| **Google Gemini** | AI 분석·메뉴 생성·Vision |

API 호출은 6개 CORS 프록시 병렬 레이스로 안정성 확보:
직접 → corsproxy.io → allorigins → codetabs → thingproxy → corsproxy.org

API 차단 시 풍부한 폴백 데이터 (서울 1,325개 + 16개 시도 약 11,000개) 자동 활용.

## 🚀 실행

브라우저에서 `index.html` 더블클릭 또는:

```bash
# 로컬 서버 (Python 3)
python -m http.server 8080

# 또는 Node.js
npx serve .
```

GitHub Pages 배포 시 자동으로 `index.html`이 진입점이 됩니다.

## ⚙️ AI 키 등록

설정 → 🤖 AI 분석 설정에서 다음 중 하나의 키 등록:
- [Claude](https://console.anthropic.com/settings/keys) (`sk-ant-api03-...`)
- [ChatGPT](https://platform.openai.com/api-keys) (`sk-proj-...`)
- [Gemini](https://aistudio.google.com/apikey) (`AIza...`)

키는 `localStorage`에만 저장되며 외부 서버로 전송되지 않습니다.
